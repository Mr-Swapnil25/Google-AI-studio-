## 🎯 Problem Statement

<div align="center">
<img src="https://user-images.githubusercontent.com/74038190/212257454-16e3712e-945a-4ca2-b238-408ad0bf87e6.gif" width="100">
</div>

India's agricultural supply chain suffers from critical inefficiencies:

| Problem | Impact |
|---------|--------|
| 🚫 **Multiple Middlemen** | Farmers receive only **30-40%** of final market price |
| 💸 **Price Opacity** | No real-time access to Mandi rates |
| ⏰ **Payment Delays** | 15-45 days typical payment cycles |
| 📉 **Quality Disputes** | No standardized grading system |
| 🌐 **Limited Market Access** | Farmers restricted to local mandis |

### 💡 Our Solution: Anna Bazaar

> **Anna (अन्न)** = Food/Grain in Hindi • **Bazaar** = Marketplace

A **B2B agricultural marketplace** that eliminates middlemen through:
- ✅ **Direct Farmer-Buyer Connections**
- ✅ **AI-Powered Quality Grading** (Google Gemini)
- ✅ **Real-time Mandi Price Integration**
- ✅ **Instant UPI/Card Payments** (DodoPayments)
- ✅ **Voice/Video Negotiation** (ZEGOCLOUD)

## 📦 Installation

<details>
<summary><b>📖 Click to expand full installation guide</b></summary>

### Prerequisites

```bash
node >= 18.x
npm >= 9.x
git
```

### Step 1: Clone Repository

```bash
git clone https://github.com/Mr-Swapnil25/Google-AI-studio-.git
cd Google-AI-studio-
```

### Step 2: Install Dependencies

```bash
npm install
```

### Step 3: Firebase Setup

1. Create project at [Firebase Console](https://console.firebase.google.com)
2. Enable **Authentication** (Email/Password, Google)
3. Create **Firestore Database**
4. Enable **Firebase Storage**
5. Copy config to `.env.local`

### Step 4: Environment Configuration

```bash
cp .env.example .env.local
```

Edit `.env.local` with your API keys:

```env
# Firebase
VITE_FIREBASE_API_KEY=your_key
VITE_FIREBASE_AUTH_DOMAIN=your-project.firebaseapp.com
VITE_FIREBASE_PROJECT_ID=your-project-id
VITE_FIREBASE_STORAGE_BUCKET=your-project.appspot.com
VITE_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
VITE_FIREBASE_APP_ID=your_app_id

# Google Gemini AI
VITE_GEMINI_API_KEY=your_gemini_key

# DodoPayments
VITE_DODO_API_KEY=your_dodo_key
VITE_DODO_MODE=test

# WeatherAPI
VITE_WEATHER_API_KEY=your_weather_key
```

### Step 5: Firestore Security Rules

Deploy these rules in Firebase Console:

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Users collection
    match /users/{userId} {
      allow read: if request.auth != null;
      allow write: if request.auth.uid == userId;
    }
    
    // Products - public read, farmer write
    match /products/{productId} {
      allow read: if true;
      allow create: if request.auth != null;
      allow update, delete: if request.auth.uid == resource.data.farmerId;
    }
    
    // Negotiations - participants only
    match /negotiations/{negId} {
      allow read, write: if request.auth != null && 
        (request.auth.uid == resource.data.buyerId || 
         request.auth.uid == resource.data.farmerId);
    }
    
    // Orders
    match /orders/{orderId} {
      allow read: if request.auth != null;
      allow create: if request.auth != null;
    }
  }
}
```

### Step 6: Run Development Server

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

### Step 7: Build for Production

```bash
npm run build
npm run preview  # Test production build locally
```

### Step 8: Deploy

```bash
# Firebase Hosting
firebase deploy

# Or Vercel
vercel --prod

# Or Netlify
netlify deploy --prod
```

</details>
